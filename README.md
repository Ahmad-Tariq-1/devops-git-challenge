# Practical Version Control Workflow

## Overview
The repository was created as part of a DevOps lab to practise source code management in Ubuntu. Git is used to track project changes, while GitHub stores the repository online.

## Repository Contents
1. `deploy.sh` — Contains a simple deployment demonstration.
2. `README.md` — Provides project information and instructions.
3. `PROOF_OF_WORK.md` — Documents the commit history and answers the lab questions.

## Working Branches
- `main`: Primary branch of the project.
- `development`: Branch for modifying the deployment script.
- `staging`: Branch for testing changes and practising conflict resolution.

## Practical Activities
This project covers Git configuration, repository cloning, staging and committing files, stashing changes, merging branches, resolving conflicts, and submitting a Pull Request.

## Learning Outcome
The repository demonstrates the use of Git commands and GitHub collaboration features to maintain and manage project versions.
